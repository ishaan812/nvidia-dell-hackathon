# GB10 connect

The product already runs on Node and local Ollama. On the Dell Pro Max you only swap the model endpoint.

1. Install Ollama ≥ 0.32.9 and pull the box model:

```bash
ollama run nemotron3:33b
```

2. Onboard NemoClaw / OpenClaw:

```bash
nemoclaw onboard
# express install → OpenClaw
```

3. Point Night Desk at the token-gated proxy (`:11435`), not raw Ollama:

```env
LLM_BASE_URL=http://127.0.0.1:11435/v1
LLM_API_KEY=<contents of ~/.nemoclaw/ollama-proxy-token>
LLM_MODEL=nemotron3:33b
```

4. Raise the context window (`NEMOCLAW_CONTEXT_WINDOW` ≥ 32768).

5. Copy `openclaw/skills/deal-diligence` into the OpenClaw workspace `skills/` folder.

6. Launch:

```bash
ollama launch openclaw --model nemotron3:33b
pnpm dev
```

Each deal is copied into `data/deals/<id>/workspace/` and the pipeline only reads that folder. You do not need OpenShell for this — OpenShell is for running untrusted agent code on Linux, which this app does not do.

The watched `inbox/` folder still works if Slack is not wired. No Python. No cloud inference.
